## QuantumArrows 1.0.0

Minecraft **26.3** Fabric 클라이언트 모드. 필요: Fabric Loader 0.19.5+, Fabric API. (선택) Mod Menu 21.0.0+

### 기능
- **화살 휠**: 활/쇠뇌를 들고 휠 클릭 → 가진 화살 종류를 원형 GUI로 표시, 마우스를 옮긴 방향으로 휠을 놓으면 대상 칸(기본: 인벤토리 맨 윗줄 2번째)에 배치
- 8종류 이상은 오른쪽 `>` 칸으로 페이지 넘김, 1000개 이상은 `1.2K` 표시, 벡터 렌더링(어떤 GUI 배율에서도 매끄러움)
- 대상 칸보다 앞에 있는 다른 화살은 뒤로 정리해 고른 화살이 실제로 발사됨 (자리가 없으면 경고 후 대상 칸으로만 이동)
- **쇠뇌 자동 장전**: 우클릭을 누르고 있어도 마지막 장전 모션에서 멈추지 않고 장전 완료
- **활 자동 발사**: 좌클릭 짧게 = 당김 단계 변경(25/50/75/100%), 꾹 누르기 = 정한 단계로 계속 발사
- 모드 메뉴 설정: 발동 조건(`HOLD ON BOW` / `EVERYTHING` / `DISABLE`), 휠 키(키 설정 메뉴와 동일), 왼손 활 인정, 쇠뇌 자동 장전, 활 자동 발사, 당김 단계
- 한국어/영어 지원

### 설치
`quantumarrows-1.0.0.jar` 를 `.minecraft/mods/` 에 넣으세요.
