## QuantumArrows 1.1.0

Minecraft **26.3** Fabric 클라이언트 모드. 필요: Fabric Loader 0.19.5+, Fabric API. (선택) Mod Menu 21.0.0+

### 변경 사항
- **모드 메뉴 아이콘 추가**: 주기율표 타일 모양의 Ar(아르곤) 아이콘 (QuantumMending의 Md 아이콘과 같은 스타일)

### 1.0.1 에서 바뀐 것
- 휠 클릭 랙 수정 (그래픽을 백그라운드에서 한 번만 계산해 텍스처로 그림)
- 선택 칸 삼각형 제거, 강조색 반투명
- 활 자동 발사: 클릭/꾹 누름 구분 0.15초, 1단계는 활이 나가는 최소 당김(3틱)

### 기능
- **화살 휠**: 활/쇠뇌를 들고 휠 클릭 → 가진 화살 종류를 원형 GUI로 표시, 마우스를 옮긴 방향으로 휠을 놓으면 대상 칸(기본: 인벤토리 맨 윗줄 2번째)에 배치
- 8종류 이상은 오른쪽 `>` 칸으로 페이지 넘김, 1000개 이상은 `1.2K` 표시, 벡터 렌더링
- 대상 칸보다 앞에 있는 다른 화살은 뒤로 정리해 고른 화살이 실제로 발사됨 (자리가 없으면 경고 후 대상 칸으로만 이동)
- **쇠뇌 자동 장전**, **활 자동 발사**(좌클릭 짧게 = 단계 변경, 꾹 누르기 = 계속 발사)
- 모드 메뉴 설정 화면: 발동 조건(`HOLD ON BOW` / `EVERYTHING` / `DISABLE`), 휠 키, 왼손 활 인정, 쇠뇌 자동 장전, 활 자동 발사, 당김 단계
- 한국어/영어 지원

### 설치
`quantumarrows-1.1.0.jar` 를 `.minecraft/mods/` 에 넣으세요.
